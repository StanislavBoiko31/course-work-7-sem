# Імітаційна модель вузла комутації повідомлень (B21)
Варіант **B21**, формалізм — **мережа масового обслуговування**.

Тема: *Імітаційна модель вузла комутації повідомлень на основі формального
опису мережею масового обслуговування.*

Алгоритм імітації власний (без SimPy та інших бібліотек імітації): час
просувається до найближчої події, стан змінюється за подіями, одночасні
події виконуються у випадковому порядку, статистика збирається зважено за
часом.

## Структура

```
switching_node/          алгоритм імітації (пакет)
  params.py              вхідні змінні та параметри (ModelParams)
  distributions.py       генератори norm(d, s) (random.gauss), unif(d, s)
                         (random.uniform) (FunRand)
  elements.py            елементи мережі МО: Element і нащадки Create,
                         RouteBlocking, Process, Dispose; Message
  node.py                SwitchingNodeModel: мережа вузла за рис. 2.1,
                         алгоритм імітації (simulate, run), вихідні
                         характеристики (Results), протокол
main.py                  один прогін із протоколом подій
experiments/             код експериментального дослідження
  common.py              серії прогонів, випадкові зерна, умови
                         експерименту, графіки
  verification.py        таблиця верифікації, фрагменти протоколу
  transient.py           перехідний період, пілот по сітці, тривалість
                         прогону (T_mod = 40 000 мкс)
  replications.py        кількість прогонів (нерівність Чебишева, p = 36)
  optimization.py        перебір + уточнення
  proposals.py           пробні прогони пропозицій, розподіл часу у вузлі
results/                 CSV і графіки (PNG, SVG), які наводяться в записці
```

## Запуск і зерна генераторів

```
python main.py                          # один прогін із протоколом подій
python -m experiments.<назва>           # verification, transient, replications,
                                        # optimization, proposals
python -m experiments.<назва> --seed N  # повторити дослід із зерном N
```

Верифікація (`verification.py`) використовує фіксоване зерно 1: усі прогони
отримують ті самі випадкові числа, тому різниця між ними спричинена лише
зміненими вхідними змінними. В експериментах зерно не фіксоване: на початку
досліду `start_experiment` бере початкове зерно з `random.SystemRandom`,
а `new_seeds` генерує з нього різні зерна для всіх прогонів. Початкове зерно
кожного досліду записується в `results/seeds.csv`; запуск із `--seed`
відтворює результати, наведені в записці.
